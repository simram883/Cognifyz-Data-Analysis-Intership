Cognifyz Data Analysis Internship
Project Overview
This project focuses on analyzing restaurant data to understand ratings, cuisines, pricing, online delivery, votes, and restaurant locations.

Objectives
- Explore and understand the restaurant dataset.
- Identify popular cuisines and cities.
- Analyze restaurant ratings and price ranges.
- Compare online delivery and table booking availability.
- Study vote distribution and restaurant locations.

Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Project Tasks
The project includes data exploration, missing-value analysis, cuisine and city analysis, rating distribution, price-range analysis, online delivery analysis, geographic distribution, restaurant name frequency, votes analysis, and table booking analysis.
files
- "Copy of cognifyz level1 anal.ipynb" — Jupyter Notebook containing the analysis and visualizations.
- "Dataset.csv" — Restaurant dataset.

Key Learning
This project helped me practice data cleaning, exploratory data analysis (EDA), visualization, and interpreting patterns in restaurant data.
